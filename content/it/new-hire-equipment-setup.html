New Hire IT Equipment and Software Setup

Overview

This guide covers the standard equipment and software Contoso provisions for new employees, and the setup steps to complete before your first day. It complements the New Employee Onboarding Checklist, which covers the broader first-90-days experience.

Equipment is ordered by HR and IT jointly once an offer is accepted, and is shipped to arrive before the employee's start date for remote hires, or set up at their desk for office-based hires. Requests for non-standard equipment require manager approval and should go through the IT asset request form.

Standard software image

All laptops ship with a standard image including Windows 11 or macOS (per role preference where applicable), Microsoft 365, the corporate antivirus/EDR agent, the GlobalProtect VPN client, and Microsoft Authenticator prerequisites. Engineers additionally receive Git, Docker Desktop, and role-specific IDEs, provisioned automatically based on the job profile selected during the hiring process.

First-day account activation

On your first day, you'll activate your account using a temporary password provided by your manager or in your welcome email. During activation, you will:

  • Set a permanent password meeting the requirements in the Password Reset and Account Security Guide.
  • Register for multi-factor authentication using the Microsoft Authenticator app.
  • Install and configure the VPN client, following the VPN Setup Guide, which is required before accessing any internal system remotely.
  • Verify access to email, the HR portal, and any team-specific systems listed by your manager.

Requesting additional software

Software not included in the standard image can be requested through the IT asset request form. Requests for software with an ongoing license cost require manager approval. Most requests are fulfilled within 2 business days; requests involving security review (for example, tools that access customer data) can take up to two weeks.

Peripherals and accessibility equipment

Additional peripherals (external keyboard, mouse, webcam) can be requested through the same asset request form. Accessibility equipment (ergonomic keyboards, screen-reading software, adjustable desks) is provided at no cost and prioritized for expedited fulfillment — contact HR or IT directly rather than using the standard request form for these requests.

Returning equipment

All company-issued equipment must be returned within 5 business days of an employee's last day, using the prepaid shipping label provided by IT for remote employees, or handed in directly to IT for office-based employees. Equipment not returned within 30 days may be treated as unreturned company property subject to the standard offboarding process.

Getting help

Delays or issues with equipment provisioning should be reported by the new hire's manager through the Help Desk Ticketing and Support Guide, flagged as a new-hire setup issue for expedited handling.
