Acceptable Use and Security Policy

Purpose

This policy defines the technical security requirements and acceptable use rules for Contoso-owned devices, accounts, and networks. It works together with the Code of Conduct, which covers the broader behavioral and confidentiality expectations of all employees.

Acceptable use of company devices

Company-issued laptops and accounts are provided for business use. Limited personal use (checking personal email, browsing during breaks) is permitted, but devices must not be used to store or transmit personal business, illegal content, or content that violates the Code of Conduct's anti-harassment provisions.

Employees may not install unauthorized software that bypasses the standard software image's security controls, including disabling antivirus/EDR agents, installing unapproved VPN or proxy software, or using personal cloud storage (Dropbox, personal OneDrive, etc.) to store company data.

Data classification

Contoso classifies data into three tiers: Public (safe for external release), Internal (business information not intended for external release, such as internal wiki pages), and Confidential (customer data, source code, financial results, HR records). Confidential data requires the handling controls described below and in the Code of Conduct's confidentiality section.

Remote and network security requirements

Consistent with the Remote Work Policy, any access to Internal or Confidential data from outside a Contoso office requires an active VPN connection — see the VPN Setup Guide for setup instructions. Split-tunneling is disabled by design so that all traffic, not just traffic to internal systems, passes through security monitoring while the VPN is connected.

Public Wi-Fi networks (cafes, airports, hotels) must never be used to access Confidential data without an active VPN connection. Home networks should use WPA2 or WPA3 encryption at minimum; employees using outdated router security should contact IT for guidance.

Authentication requirements

All accounts require multi-factor authentication as described in the Password Reset and Account Security Guide. Shared accounts (a single login used by multiple people) are prohibited except for specifically approved service accounts managed by IT.

Monitoring

Contoso monitors network traffic, email, and endpoint activity on company-owned devices and accounts for security purposes, including detection of malware, data exfiltration, and policy violations. Employees should have no expectation of privacy when using company systems, consistent with the Code of Conduct's section on use of company property.

Incident reporting

Suspected security incidents — a lost or stolen laptop, a suspected phishing click, unusual account activity, or a suspected malware infection — must be reported immediately to the IT help desk as a Severity 1 issue per the Help Desk Ticketing and Support Guide. Do not wait to confirm the issue is real before reporting; a false alarm is far preferable to a delayed report of a real incident.

Consequences of violation

Violations of this policy are handled through Contoso's standard disciplinary process described in the Code of Conduct. Depending on severity, consequences may range from a documented warning and mandatory retraining to termination, particularly for violations involving intentional circumvention of security controls or unauthorized disclosure of Confidential data.

Policy review

Employees are required to acknowledge this policy annually as part of mandatory compliance training, referenced in the New Employee Onboarding Checklist for new hires and repeated yearly for all employees thereafter.
